Siva Kumar Bokam — AI Engineer Portfolio
A personal portfolio showcasing my work in Python, Machine Learning, Generative AI, RAG and agentic applications.

View locally
Open index.html in a web browser.

Publish with GitHub Pages
1. Create a GitHub repository named portfolio.
2. Upload index.html and the other project assets.
3. Go to Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the main branch and / (root), then click Save.
   
Your website will be available at:

https://<your-github-username>.github.io/portfolio/

Note
The interactive project previews are illustrative demos. They do not connect to live project backends unless separately integrated.
